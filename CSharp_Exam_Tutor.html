บทที่ 1 • ITERATION STATEMENTS

Loop (คำสั่งทำซ้ำใน C#)

เข้าใจกลไก Pretest vs Posttest Loop, Components of Loop, Jump Statements (break/continue), Infinite Loop และ Nested Loop

1. แนวคิดหลักและองค์ประกอบของ Loop (Components of Loop)

ในเอกสารเรียนแบ่ง Iteration Statements ออกเป็น 3 กลุ่มหลัก ได้แก่:

  • Conditional iteration: ทำซ้ำตามเงื่อนไข ได้แก่ while และ do...while
  • Definite iteration: ทำซ้ำตามจำนวนรอบที่แน่นอน ได้แก่ for
  • Traversing items in a collection: วนอ่านสมาชิกทีละตัวใน Array/Collection ได้แก่ foreach
ประเภทการทดสอบเงื่อนไข คำสั่ง Loop หลักการทำงานสำคัญ (ออกสอบบ่อย!)
Pretest Loop
(ตรวจสอบเงื่อนไขก่อนทำ)		 for, while, foreach เช็กเงื่อนไข ก่อน เริ่มทำงานในรอบนั้น หากเป็น false ตั้งแต่แรก จะไม่ทำงานเลย (0 รอบ)
Posttest Loop
(ทำงานก่อนตรวจสอบเงื่อนไข)		 do...while ทำงานในบล็อก do { ... } ก่อนอย่างน้อย 1 รอบเสมอ แล้วค่อยเช็กเงื่อนไขที่ while(...); (อย่าลืมเครื่องหมาย ; ปิดท้าย!)
3 องค์ประกอบบังคับของ Loop (START - STOP - STEP):
1. Initialization (START): จุดเริ่มต้นของตัวแปรควบคุมลูป (เช่น int i = 1;)
2. Condition (STOP): เงื่อนไขในการทำงานต่อ หากเป็นจริง (True) ทำต่อ หากเป็นเท็จ (False) หยุดลูป
3. Counter / Updating step (STEP): การปรับค่าตัวแปรควบคุมลูป (เช่น i++ หรือ i--) เพื่อไม่ให้เกิด Infinite Loop
2. Syntax และรูปแบบการเขียนโค้ดทั้ง 4 แบบ
C# Loop Syntax & ตัวอย่างการทำงานจริง
using System;

public class LoopDemo {
    public static void Main() {
        // 1. for loop (Pretest - Definite)
        for (int i = 1; i <= 3; i++) {
            Console.Write(i + " ");
        }
        Console.WriteLine();

        // 2. while loop (Pretest - Conditional)
        int w = 10;
        while (w < 5) { // เงื่อนไขเป็น false ตั้งแต่ต้น -> ไม่ทำงานเลย
            Console.WriteLine("While run");
            w++;
        }

        // 3. do...while loop (Posttest - ทำก่อน 1 รอบเสมอ)
        int d = 10;
        do {
            Console.WriteLine("Do-While run once: d = " + d);
            d++;
        } while (d < 5); // ต้องมี ; ปิดท้ายเสมอ!

        // 4. foreach loop (Pretest - วนอ่าน Array ตั้งแต่ index 0 ถึง Length - 1)
        int[] scores = { 80, 90, 100 };
        foreach (int s in scores) {
            Console.Write(s + " ");
        }
    }
}
1 2 3 Do-While run once: d = 10 80 90 100

คำอธิบายโค้ดและผลลัพธ์ทีละส่วน:

  • for วนตั้งแต่ i = 1 ถึง 3 พิมพ์ 1 2 3
  • while (w < 5) เนื่องจาก w = 10 เงื่อนไขเป็นเท็จทันที จึงข้ามบล็อกนี้ไป
  • do...while แม้ d = 10 จะไม่น้อยกว่า 5 แต่เพราะเป็น Posttest จึงพิมพ์ Do-While run once: d = 10 ออกมาก่อน 1 ครั้ง แล้วค่อยเช็กเงื่อนไขและจบการทำงาน
  • foreach อ่านค่าจาก scores ทีละตัวเรียงจาก index 0 ไปจนถึง Length - 1 (ข้อจำกัด: ไม่สามารถใช้แก้ไขค่าสมาชิกใน Array โดยตรงได้)
3. Jump Statements (break vs continue) และ Nested Loop

Jump Statement ใช้ควบคุมการกระโดดข้ามในลูป:

  • break; : หยุดและออกจากลูปทันที (Break out of the loop entirely)
  • continue; : ข้ามคำสั่งที่เหลือในรอบปัจจุบัน แล้วกระโดดไปเช็กเงื่อนไข/อัปเดตค่าในรอบถัดไปทันที
จุดหลอกในข้อสอบเรื่อง continue ใน while / do...while:
หากเขียน i++; ไว้ หลัง continue; ในลูป while เมื่อเจอ continue โปรแกรมจะข้าม i++ ทำให้ค่า i ไม่เปลี่ยนและเกิด Infinite Loop ทันที! (ต่างจาก for ที่ส่วน i++ ในหัวลูปยังทำงานเสมอ)
ตัวอย่างจากสไลด์: break vs continue และ Nested Loop
// ตัวอย่าง Jump Statement จากสไลด์หน้า 12
for (int i = -5; i <= 5; i++) {
    if (i == 0) break;
    Console.Write(i + " "); // ผลลัพธ์: -5 -4 -3 -2 -1 (หยุดทันทีเมื่อ i == 0)
}

for (int i = -5; i <= 5; i++) {
    if (i == 0) continue;
    Console.Write(i + " "); // ผลลัพธ์: -5 -4 -3 -2 -1 1 2 3 4 5 (ข้ามเลข 0)
}

// ตัวอย่าง Nested Loop (ลูปซ้อนลูป) จากสไลด์หน้า 14
// หลักการ: ลูปในทำงานครบทุกรอบก่อน ลูปนอกจึงขยับ 1 รอบ
for (int r = 5; r >= 1; r--) {
    for (int c = 1; c <= r; c++) {
        Console.Write("x");
    }
    Console.WriteLine();
}
xxxxx xxxx xxx xx x
เทคนิคจำและข้อผิดพลาดที่พบบ่อย:
• Infinite Loop เกิดจาก 3 สาเหตุ: 1) ลืมใส่ START, STOP หรือ STEP (เช่น for(int i=1; i<=10;)) 2) ลำดับผิด/เงื่อนไขไม่ถึงจุดหยุด (เช่น int i=1; while(i>0) { i++; }) 3) ตั้งใจเขียน (while(true) ซึ่งต้องมี break)
• จำนวนรอบรวมของ Nested Loop = จำนวนรอบลูปนอก × จำนวนรอบลูปใน (กรณีรอบคงที่)

บทที่ 2 • เน้นพิเศษออกสอบหนัก ★

Method (เมธอดและการส่งผ่านค่าใน C#)

เจาะลึกโครงสร้าง Method 5 ส่วน, ประเภทของ Method ทั้ง 4 รูปแบบตาม Parameter และ Return Type, การเรียกใช้และการส่งค่ากลับ

1. แนวคิดและองค์ประกอบพื้นฐานของ Method (5 Components)

Method คือกลุ่มของชุดคำสั่งที่รวมไว้ทำงานเฉพาะอย่าง ช่วยแบ่งโปรแกรมใหญ่ให้เป็นส่วนย่อย อ่านเข้าใจง่าย และนำกลับมาใช้ซ้ำได้ (Code Reuse) โดยชื่อ Method ควรตั้งเป็นคำกริยา (Verb) และขึ้นต้นด้วยตัวพิมพ์ใหญ่ (PascalCase)

กฎเหล็กตำแหน่งการสร้าง Method:
ต้องประกาศ Method ไว้นอก Main() แต่อยู่ภายใน class เดียวกัน (ห้ามซ้อน Method ไว้ใน Main) และหากเรียกใช้จาก static void Main() โดยไม่สร้าง Object จะต้องใส่คำว่า static กำกับด้วยเสมอ
โครงสร้าง 5 ส่วนของ Method
// [1. Modifier] [static] [2. Return_Type] [3. Method_Name] ( [4. Parameter(s)] )
public static int CalculateArea(int width, int height)
{
    // [5. Method Body]
    int area = width * height;
    return area; // ส่งค่าชนิด int กลับไปยังจุดที่เรียกใช้
}
ส่วนประกอบ หน้าที่และรายละเอียด ตัวอย่าง
1. Modifier กำหนดสิทธิ์การเข้าถึง (Access Modifier) public, private
2. Return Type ชนิดข้อมูลที่ส่งกลับ ถ้าไม่ส่งค่ากลับต้องใช้ void int, double, string, int[], void
3. Method Name ชื่อเมธอด แนะนำขึ้นต้นด้วยตัวใหญ่และเป็นคำกริยา SayHi, GetNumMajor, Sum
4. Parameter(s) ตัวแปรที่ประกาศในวงเล็บ () เพื่อรับค่าจากผู้เรียก (คั่นด้วย ,) (string name, int age)
5. Method Body ชุดคำสั่งภายในปีกกา { ... } คำสั่งคำนวณและ return
2. ประเภทของ User-Defined Method ทั้ง 4 รูปแบบ (ออกสอบแน่นอน!)

ในสไลด์แบ่งประเภทของ Method ตาม Parameter และ Return Data ออกเป็น 4 แบบ ดังนี้:

ตัวอย่างครบทั้ง 4 รูปแบบของ Method (รันได้จริง)
using System;

public class MethodFourTypes {
    public static void Main(string[] args) {
        // แบบที่ 1: No parameter + No return data -> เรียกชื่อโดดๆ
        SayHi();

        // แบบที่ 2: No parameter + Return data -> ต้องเอาตัวแปรมารับ หรือพิมพ์ค่าทันที
        int majors = GetNumMajor();
        Console.WriteLine("IT school has {0} majors.", majors);

        // แบบที่ 3: Parameter(s) + No return data -> ส่ง Argument ให้ตรงชนิดและลำดับ
        ShowName("Lisa", 23);

        // แบบที่ 4: Parameter(s) + Return data -> ส่งค่าเข้าไปคำนวณแล้วรับผลลัพธ์กลับ
        int total = Sum(9, 4);
        Console.WriteLine("Sum = " + total);
    }

    // 1. No parameter + No return
    public static void SayHi() {
        Console.WriteLine("Hello, Sawasdee");
    }

    // 2. No parameter + Return int
    public static int GetNumMajor() {
        int numMajor = 5;
        return numMajor;
    }

    // 3. Parameter(s) + No return
    public static void ShowName(string name, int age) {
        Console.WriteLine("Hello " + name + ", age " + age);
    }

    // 4. Parameter(s) + Return int
    public static int Sum(int num1, int num2) {
        return num1 + num2;
    }
}
Hello, Sawasdee IT school has 5 majors. Hello Lisa, age 23 Sum = 13
ความแตกต่างระหว่าง Parameter vs Argument และกฎการ Return:
• Parameter: ตัวแปรที่ประกาศตรงหัว Method (เช่น int num1, int num2)
• Argument: ค่าจริงหรือตัวแปรที่ส่งเข้าไปตอนเรียกใช้ Method (เช่น Sum(9, 4) หรือ Sum(tmpNum1, tmpNum2)) ต้องมีจำนวน ชนิดข้อมูล (Data Type) และลำดับตรงกัน
• กฎของ return:
1) ถ้า Return Type ไม่ใช่ void ทุกเส้นทางของโค้ด (เช่น ใน if-else) ต้องมีคำสั่ง return และค่าที่ส่งกลับต้องตรงชนิด
2) ทันทีที่โปรแกรมทำงานถึงบรรทัด return ...; Method จะจบการทำงานทันที คำสั่งที่อยู่ใต้ return จะไม่ถูกทำงาน
3) Method ที่เป็น void ห้ามเขียน return value; (เขียนได้แค่ return; เปล่าๆ เพื่อออกก่อนกำหนด)
🧠 Flashcards ทบทวนความจำ (ทบทวนบทที่ 1: Loop)

กดปุ่ม "พลิกดูคำตอบ" เพื่อเช็กความแม่นยำของเนื้อหาบทก่อนหน้า

ทบทวน Loop #1
หากกำหนดค่าเริ่มต้น int x = 20; ลูป while (x < 10) กับ do { ... } while (x < 10); จะทำงานต่างกันอย่างไร?
คำตอบ:
• while เป็น Pretest Loop เช็กเงื่อนไขก่อน (20 < 10 เป็น False) จึงทำงาน 0 รอบ
• do...while เป็น Posttest Loop ทำงานก่อน 1 รอบ แล้วค่อยเช็กเงื่อนไข จึงทำงาน 1 รอบ (และต้องมี ; หลัง while)
ทบทวน Loop #2
ในลูป for (int i = 1; i <= 5; i++) หากเจอ if (i == 3) continue; ค่าตัวแปร i จะยังถูกอัปเดตด้วย i++ หรือไม่?
คำตอบ:
อัปเดตครับ! ใน for loop คำสั่ง continue จะข้ามคำสั่งที่เหลือในปีกกา แล้วกระโดดไปทำส่วน STEP (i++) จากนั้นจึงเช็กเงื่อนไข i <= 5 ต่างจาก while ที่อาจเกิด Infinite Loop หากวาง i++ ไว้หลัง continue

บทที่ 3 • เน้นพิเศษออกสอบหนัก ★

Array (อาร์เรย์ 1 มิติ, 2 มิติ และการส่งผ่าน Method)

เจาะลึก Index 0 ถึง Length - 1, การประกาศและสร้าง Array, การส่ง Array เข้า/ออกจาก Method, และ 2D Array กับ GetLength(0) / GetLength(1)

1. แนวคิด การประกาศ และการกำหนดค่า Array 1 มิติ

Array คือกลุ่มของข้อมูลที่มีชนิดข้อมูลเดียวกัน (Same Data Type) เก็บเรียงต่อกันในหน่วยความจำ สมาชิกแต่ละตัวเรียกว่า Element เข้าถึงผ่านตำแหน่ง Index โดย Index เริ่มต้นที่ 0 เสมอ และตัวสุดท้ายอยู่ที่ Length - 1 (Upper Bound)

รูปแบบการประกาศและสร้าง Array 1 มิติ (ตามสไลด์หน้า 25)
// 1. Declaration (ประกาศตัวแปรอาร์เรย์)
string[] students;
int[] nums;

// 2. Creation (จองขนาดหน่วยความจำด้วย new)
students = new string[3]; // Index คือ 0, 1, 2
nums = new int[5];        // Index คือ 0, 1, 2, 3, 4 (ค่าเริ่มต้นของ int คือ 0)

// 3. Combine Declaration & Creation (ประกาศพร้อมจองขนาด)
float[] price = new float[10];

// 4. Initialization (ประกาศพร้อมกำหนดค่าเริ่มต้น)
int[] num1 = new int[3] { 1, 2, 3 };
int[] num2 = { 1, 2, 3 }; // แบบย่อ (C# นับขนาดให้อัตโนมัติ = 3)
ข้อผิดพลาดอันดับ 1 ของเรื่อง Array (IndexOutOfRangeException):
ถ้าประกาศ int[] value = new int[9]; จะมี value.Length == 9 แต่ Index ที่ใช้ได้คือ 0 ถึง 8 เท่านั้น!
หากเขียนลูป for (int i = 0; i <= value.Length; i++) (ใช้ <= แทน <) โปรแกรมจะพังทันทีเมื่อ i = 9 เพราะไม่มี value[9]!
2. การส่ง Array เข้าและออกจาก Method (ออกสอบบ่อยมาก!)

Method ปกติส่งค่ากลับได้เพียง 1 ค่า แต่เราสามารถใช้ Array เพื่อส่งข้อมูลหลายค่าเข้าหรือออกจาก Method ได้ 3 ลักษณะตามสไลด์:

  • ส่งสมาชิกตัวเดียว (Single Element): เช่น Add2Values(arr[0], arr[2]) พารามิเตอร์รับเป็นตัวแปรธรรมดา (int v1, int v2)
  • ส่งทั้ง Array (Whole Array): เช่น Summation(arr) ใส่แค่ชื่อตัวแปรอาร์เรย์ ไม่ต้องใส่ [] ตอนเรียก ส่วนหัว Method รับเป็น (int[] a)
  • คืนค่ากลับเป็น Array (Return Array): กำหนด Return Type เป็น int[] และ return a; (ส่งแค่ชื่อตัวแปรอาร์เรย์)
ตัวอย่างครบสูตร: ส่ง Element, ส่งทั้ง Array และ Return Array
using System;

public class ArrayMethodDemo {
    public static void Main() {
        int[] arr = { 10, 20, 30 };

        // 1. ส่งสมาชิกบางตัว (Pass by Value)
        Console.WriteLine("Sum 2 elements = " + Add2Values(arr[0], arr[2]));

        // 2. ส่งทั้ง Array เข้า Method (Pass by Reference - แก้ไขค่าข้างในกระทบตัวจริง!)
        Console.WriteLine("Total = " + Summation(arr));

        // 3. รับ Array ที่ Return กลับมาจาก Method
        int[] generated = SetNumber();
        foreach (int x in generated) {
            Console.Write(x + " ");
        }
    }

    public static int Add2Values(int v1, int v2) {
        return v1 + v2;
    }

    public static int Summation(int[] a) {
        int sum = 0;
        for (int i = 0; i < a.Length; i++) {
            sum += a[i];
        }
        return sum;
    }

    public static int[] SetNumber() {
        int[] temp = { 1, 2, 3, 4, 5 };
        return temp;
    }
}
Sum 2 elements = 40 Total = 60 1 2 3 4 5
3. Multidimensional Arrays (Array 2 มิติ) และ Properties สำคัญ

Array 2 มิติ ใช้เครื่องหมายจุลภาค [,] ภายในวงเล็บเหลี่ยม (C# รองรับสูงสุด 32 มิติ) มองเป็นตาราง [แถว (Row), คอลัมน์ (Column)]

Property / Method หน้าที่ (ตัวอย่าง int[,] arr = new int[4, 2];) ค่าที่ได้
arr.Length จำนวนสมาชิกทั้งหมดทุกช่องรวมกัน (4 × 2) 8
arr.Rank จำนวนมิติของอาร์เรย์ 2
arr.GetLength(0) ขนาดของมิติที่ 1 = จำนวนแถว (Rows) 4
arr.GetLength(1) ขนาดของมิติที่ 2 = จำนวนคอลัมน์ (Columns) 2
การใช้ Nested Loop วนอ่าน Array 2 มิติ (สไลด์หน้า 33)
int[,] a = new int[3, 2] { { 11, 12 }, { 21, 22 }, { 31, 32 } };

for (int r = 0; r < a.GetLength(0); r++) {       // วนแถว (0 ถึง 2)
    for (int c = 0; c < a.GetLength(1); c++) {   // วนคอลัมน์ (0 ถึง 1)
        Console.Write("a[{0},{1}]={2}  ", r, c, a[r, c]);
    }
    Console.WriteLine();
}
a[0,0]=11 a[0,1]=12 a[1,0]=21 a[1,1]=22 a[2,0]=31 a[2,1]=32

ทบทวน Loop
หากต้องการอ่านสมาชิกทุกตัวใน Array โดยไม่ต้องใช้ตัวนับ Index และไม่ต้องการแก้ไขค่าใน Array ควรใช้ลูปใด?

ใช้ foreach (DataType varName in arrayName) เพราะอ่านเรียงจาก Index 0 ถึง Length - 1 อัตโนมัติ ไม่เสี่ยงเกิด IndexOutOfRangeException
ทบทวน Method
หากประกาศ Method public static double Calc(int a, double b) ข้อใดเรียกใช้ผิด:
A) double x = Calc(5, 2.5);
B) Calc(2.5, 5);
คำตอบ:
ข้อ B ผิด! เพราะ Argument ตัวแรกส่ง 2.5 (double) เข้าไปใน Parameter int a ซึ่ง C# ไม่อนุญาตให้แปลง double เป็น int อัตโนมัติ (Type Mismatch)

บทที่ 4 • OBJECT ORIENTED PROGRAMMING (OOP)

Class & Object (คลาส ออบเจกต์ พร็อพเพอร์ตี้ และคอนสตรัคเตอร์)

เข้าใจ Blueprint vs Instance, Encapsulation, Access Modifiers, Field vs Property (get/set), Constructor Overloading และ Array of Class

1. แนวคิด OOP: Class, Object, Encapsulation และ Modifier
  • Class (คลาส): คือแม่แบบ (Blueprint) สำหรับสร้างออบเจกต์ ประกอบด้วย Attributes/Fields (สถานะ/ข้อมูล) และ Behaviors/Methods (พฤติกรรม/การทำงาน) (1 Class สามารถสร้างได้ Many Objects)
  • Object (ออบเจกต์ / Instance): คือตัวตนจริงที่ถูกสร้างขึ้นจาก Class โดยใช้คำสั่ง new เช่น Student s1 = new Student();
  • Encapsulation (การห่อหุ้มข้อมูล): การรวม Field และ Method ไว้ใน Class เดียวกัน และซ่อนข้อมูลภายใน (private) โดยเปิดให้เข้าถึงผ่าน public Property หรือ public Method
  • Modifiers (ตามสไลด์หน้า 40):
    • public : เข้าถึงได้จากทุกคลาส (ใน UML ใช้สัญลักษณ์ +)
    • private : เข้าถึงได้เฉพาะภายในคลาสเดียวกันเท่านั้น (ใน UML ใช้สัญลักษณ์ -)
2. Field, Property (get / set) และ Constructor

Field (Backing Field): ตัวแปรที่ประกาศในขอบเขตของ Class (Class Scope) มักกำหนดเป็น private เพื่อป้องกันการแก้ไขโดยตรงจากภายนอก

Property: ส่วนผสมระหว่างตัวแปรและเมธอด ใช้เป็นตัวกลางเข้าถึง private field ประกอบด้วย 2 ส่วนคือ:

  • get accessor: อ่าน/คืนค่าจาก Field
  • set accessor: กำหนดค่าให้ Field โดยใช้คีย์เวิร์ดพิเศษชื่อ value แทนค่าที่ส่งเข้ามา

Constructor (คอนสตรัคเตอร์): เมธอดพิเศษของ Class ที่ทำงานอัตโนมัติเมื่อสร้าง Object ด้วย new มีกฎเหล็ก 3 ข้อ (ตามสไลด์หน้า 47):

  1. ชื่อต้องเหมือนชื่อ Class ทุกตัวอักษร
  2. ห้ามมี Return Type (แม้แต่ void ก็ห้ามใส่!) และไม่ใช่ static
  3. 1 Class มีได้หลาย Constructor (Overloading) โดยต้องมี Parameter ต่างกัน (หากไม่เขียนเลย C# จะมี Default Constructor ว่างๆ ให้ แต่ถ้าเขียนแบบมี Parameter แล้ว Default Constructor แบบไม่มี Parameter จะหายไปทันที!)
ตัวอย่างครบเครื่อง: Field, Property 3 แบบ, Constructor Overloading และ Array of Class
using System;

public class Person {
    // 1. Private Backing Fields
    private string first;
    private string last;

    // 2. Custom Property (แบบเต็ม)
    public string First {
        get { return first; }
        set { first = value; } // value คือคีย์เวิร์ดรับค่าที่ส่งมา
    }

    // Expression-bodied Property (แบบลูกศรตามสไลด์หน้า 46)
    public string Last {
        get => last;
        set => last = value;
    }

    // Auto-implemented Property (แบบย่อ ไม่ต้องสร้าง field เอง)
    public int Age { get; set; }

    // 3. Constructors (Overloading 3 แบบ)
    public Person() {
        first = "Unknown";
        last = "Unknown";
    }

    public Person(string firstName) {
        first = firstName;
        last = "";
    }

    public Person(string firstName, string lastName) {
        first = firstName;
        last = lastName;
    }

    // 4. Method Member
    public void ShowInfo() {
        Console.WriteLine(first + " " + last);
    }
}

public class MainPerson {
    public static void Main() {
        // Array of Class (สไลด์หน้า 49)
        Person[] people = new Person[3]; // สร้างช่องอ้างอิง 3 ช่อง (ยังเป็น null!)
        people[0] = new Person();
        people[1] = new Person("Toby");
        people[2] = new Person("Laura", "White");

        people[1].Last = "Green"; // เรียกใช้ set ของ Property Last

        for (int i = 0; i < people.Length; i++) {
            people[i].ShowInfo();
        }
    }
}
Unknown Unknown Toby Green Laura White
กับดักข้อสอบเรื่อง Array of Class:
คำสั่ง Person[] p = new Person[3]; เป็นเพียงการจองพื้นที่ Array 3 ช่องสำหรับเก็บ Reference เท่านั้น (ค่าข้างในยังเป็น null) ต้องใช้คำสั่ง p[i] = new Person(); สร้าง Object ทีละช่องก่อน มิฉะนั้นจะเกิด NullReferenceException!
🧠 Flashcards ทบทวนความจำ (ทบทวนบทที่ 2: Method & บทที่ 3: Array)
ทบทวน Method
ถ้าส่งตัวแปร int x = 10; เข้าไปใน Method void AddFive(int n) { n += 5; } ค่า x ใน Main จะเปลี่ยนเป็น 15 หรือไม่?
คำตอบ:
ไม่เปลี่ยนครับ! x ใน Main ยังเป็น 10 เหมือนเดิม เพราะชนิดข้อมูลพื้นฐาน (int, double, bool) ส่งแบบ Pass by Value (คัดลอกค่าไปให้ n)
ทบทวน Array
กำหนด int[,] m = new int[3, 5]; ค่าของ m.Length, m.GetLength(0) และ m.GetLength(1) คือเท่าไรตามลำดับ?
คำตอบ:
• m.Length = 15 (3 × 5 ช่องทั้งหมด)
• m.GetLength(0) = 3 (จำนวนแถว)
• m.GetLength(1) = 5 (จำนวนคอลัมน์)

C# Exam Cheat Sheet

รวบรวม Syntax สำคัญทั้ง 4 บท จุดที่มักออกสอบ และข้อควรระวังที่ห้ามพลาด

1. Loop Syntax & Jump
// for (Pretest - Definite)
for (int i = 0; i < n; i++) { }

// while (Pretest - เช็กก่อนทำ: 0..N รอบ)
while (condition) { }

// do..while (Posttest - ทำก่อนเช็ก: 1..N รอบ)
do { } while (condition); // มี ;

// foreach (Pretest - อ่านอย่างเดียว แก้ค่าไม่ได้)
foreach (int x in arr) { }

• break = ออกจากลูปทันที | continue = ข้ามรอบนี้ไปรอบถัดไป

2. Method & Parameter / Return
// ประกาศนอก Main() แต่อยู่ใน Class
public static ReturnType MethodName(Type p1, Type p2) {
    return value; // ถ้าไม่ใช่ void ต้องมี return
}

// การส่งและคืนค่า Array
public static int[] Process(int[] data) {
    return data; // ส่งแค่ชื่อ ไม่ต้องใส่ []
}

• Primitive (int/double) = Pass by Value | Array/Object = Pass by Reference

3. Array 1D & 2D
// 1D Array (Index: 0 ถึง Length - 1)
int[] a = new int[5];
int[] b = { 10, 20, 30 };

// 2D Array [row, col]
int[,] m = new int[3, 4];
// m.Length == 12 | m.Rank == 2
// m.GetLength(0) == 3 (Rows)
// m.GetLength(1) == 4 (Cols)
4. Class, Property & Constructor
public class Book {
    private string title; // Field
    public string Title { // Property
        get { return title; }
        set { title = value; }
    }
    public int Pages { get; set; } // Auto
    public Book(string t) { title = t; } // Constructor
}
Book[] list = new Book[2]; // ต้อง new list[i] ทีละช่อง!
⚠️ Top 8 ข้อผิดพลาดที่ทำให้เสียคะแนนในห้องสอบ
  1. ลืมเครื่องหมาย ; หลัง while(condition); ในลูป do...while
  2. เขียนเงื่อนไข i <= arr.Length ทำให้เกิด IndexOutOfRangeException (ต้องเป็น i < arr.Length)
  3. พยายามแก้ไขค่าสมาชิกในลูป foreach (int x in arr) { x = 10; } (Compile Error!)
  4. ประกาศ Method ซ้อนอยู่ใน Main() หรือลืมใส่ static เมื่อเรียกจาก Main()
  5. ใส่ [] ตอนส่งชื่อตัวแปร Array เข้า Method เช่น Sum(arr[]) (ที่ถูกคือ Sum(arr))
  6. ใช้ arr.Length กับ Array 2 มิติในเงื่อนไขลูปแถว (ต้องใช้ arr.GetLength(0) สำหรับแถว และ arr.GetLength(1) สำหรับคอลัมน์)
  7. ใส่ void หน้าชื่อ Constructor เช่น public void Student() (จะกลายเป็น Method ธรรมดา ไม่ใช่ Constructor)
  8. สร้าง Student[] s = new Student[5]; แล้วเรียก s[0].Name ทันทีโดยยังไม่ s[0] = new Student();
